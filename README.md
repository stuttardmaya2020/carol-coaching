# Carol Fox Coaching: website redesign

A redesign of Carol Fox's coaching website, run as a lean user-centred design process and documented as a portfolio case study.

- **Designer:** Maya Stuttard
- **Client:** Carol Fox, life and business coach (London, in person and remote)
- **Tools:** Claude Code with the impeccable plugin, Figma, GitHub Pages
- **Kickoff:** Mon 19 Oct 2026

## Process

1. **Discover:** kickoff call (done), current-site audit (done), comparable site review
2. **Define:** problem statement, HMWs, proto-personas, content strategy, sitemap, voice and tone (first draft done)
3. **Design:** mood boards, wireframes, visual build with Claude Code
4. **Review with Carol:** send the package, collect feedback
5. **Test:** walkthrough with Carol plus 3 to 5 people of mixed ages
6. **Launch:** preview on GitHub Pages, then move to Carol's domain once she approves
