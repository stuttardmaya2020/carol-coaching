Mood board starter

Two visual directions for Carol to react to, each laid out as a ready-made mood board. Rebuild them in Figma, swap the grey boxes for real images, then send Carol both and ask which feels more like her.

The layout

Every board uses the same layout, so Carol compares the feeling of each direction rather than the arrangement. One large image sets the mood, two smaller ones add range, and the right-hand column shows how the site would speak and look.

Build it in Figma

  1. Create the file. In Figma, choose New design file and name it "Carol Fox mood boards". This uses one of your three free files.
  2. Add two frames. Press F, then drag out a frame and set its size to 1920 × 1080 in the right-hand panel. Name it "A: Warm editorial". Duplicate it with ⌘ D, move it to the right and rename it "B: Modern confident".
  3. Add a grid to help you line things up. Select a frame, then in the right-hand panel add a layout guide with 12 columns, a 64 px margin and a 24 px gutter. The hero takes 5 columns, the middle images 3, and the right column 4.
  4. Drop in the images. Drag photos straight from Finder onto the frame. Draw a rectangle (R) for each zone first, then drag the image onto the rectangle so it fills and crops automatically. Double-click the image to adjust the crop.
  5. Add the colours. Draw five 120 × 120 squares, paste each hex code from this page into the Fill field (click a swatch here to copy it), and add a small text label underneath with T.
  6. Add the type and words. Type the sample headline and set the font from the text panel. Google Fonts are built in, so search "Newsreader" or "Bricolage Grotesque". Add the three mood words and a button shape with the call to action.
  7. Keep it consistent. Same layout, same number of images, and the same spacing on both boards. If Direction A's images are black and white, make all of them black and white.
  8. Export and save. Select each frame and add an export in the bottom of the right-hand panel: PNG at 2×. Save the files to design/mood-boards/ in the repo, and add a line to the design log.

Finding images

Unsplash and Pexels are free, with no attribution needed. Try these searches:

  • "two women coffee conversation"
  • "mentor young professional"
  • "older woman portrait black and white"
  • "graduate first job office"
  • "business meeting relaxed laughing"

Using Carol's photos

  • Use her existing black-and-white portraits for the hero.
  • Leave out the old home page photo with Jane.
  • The photo with Alfie is optional. He has passed away, so check with Carol before using it.
  • Mix ages across the board so every visitor sees someone like them.

Keep it light

  • 8 to 10 images per board at most.
  • Aim for 1 to 2 hours in total. The aim is a quick reaction from Carol, not a final design.
  • Screenshot your boards as you go for the case study.

What to send Carol

Send both boards side by side, with one short message:

"Here are two directions for the new site. Which one feels more like you, and is there anything you'd change?"

Her answer, and the reasons she gives, go straight into the design log. That's the evidence your case study needs for why the final design looks the way it does.
